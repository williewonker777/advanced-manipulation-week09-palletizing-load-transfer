## 국소 안정성: R1과 함께 해석하기

강제점은 R1 관측·물리점에 후보 제어기를 재생한 점, 실제 후보점은 후보 자체 궤적의 점이다. radius는 이산 폐루프 고유값의 최대 절댓값이고 FD는 유한차분 수렴 검사다. 아래 분자는 두 관문을 동시에 통과한 수다.

| 후보 | 강제점 통과 | 실제 후보점 통과 | 같은 강제점 R1 |
|---|---|---|---|
| A_handoff_short | 22/28 | 미실행: 비선정 | 22/28 |
| A_handoff_long | 22/28 | 54/64 | 22/28 |
| B_phase | 45/50 | 미실행: 비선정 | 46/50 |
| B_mass | 43/50 | 45/48 | 46/50 |
| B_mass_phase | 45/50 | 미실행: 비선정 | 46/50 |

R1 열은 같은 **강제점 격자**만 비교하며 후보 실제점에 대응하는 R1 재실행은 아니다.

- 임계값은 R2와 같지만 검사점은 R3에서 늘었다. A의 강제 실패 6점과 실제 실패 10점은 모두 추가한 3.1–3.6 s 구간이고 기존 2.5, 3.75, 3.89 s에는 없다.
- A의 강제 실패 6점은 R1도 같은 점에서 실패했다. 강제 실패 6점에서, 두 설정을 통틀어 R1 대비 radius 차이 최대는 3.78e-05로 약 3.8e-5다.
- B-mass의 강제 실패 7점은 radius 실패 3점과 radius 통과·FD 미수렴 4점이다. radius 실패 3점은 R1도 실패했고, 5.65/4.4 kg의 2.5 s 두 점은 B가 1에 더 가깝다. R1이 실패한 7.7 kg, 2.5 s는 B가 통과했다.
- 같은 강제점 R1은 R1 관측·물리점 격자의 비교이며 후보 실제 궤적의 R1 재생이 아니다. 이 국소 관문만으로 후보와 R1을 가를 수 없다. 규칙과 탈락 판정은 그대로 두고 D4·섭동 비용·오감지 근거를 함께 판단한다.
- D4 전체 385조건에서 R1 A도 포화 4회/최대 0.166667%로 상한 2회/0.15%를 넘었다. A-long도 4회이고 최대율은 0.150000%다. 무충돌 189조건의 2회와 혼동하지 않는다.

## 재설계 기록과 원인 분석의 한계

재설계는 **A 0회, B 0회**다. 당시 A는 비용 외 국소 관문도 실패했고 추가 시각·gain을 정할 원인이 완전히 식별되지 않았다. B-mass는 사전 검증 비용·효능을 통과해 비용 중심 재설계 발동 조건이 아니었다.

- 재설계 결정은 R1 비교 파일보다 먼저 저장됐다. 결정은 연구 작업 커밋 5a86c02, R1 비교 파일은 그 뒤 커밋 8b57c79에서 추가됐다. 두 커밋은 비공개 작업 이력이라 공개 이력에서는 찾을 수 없다. A의 당시 국소 관문 실패는 그 뒤 R1과 같은 위치로 확인돼 단독 식별 근거가 약해졌다.
- 결정 기록 자체는 바꾸지 않는다. 질량별 비선형 위상·원인 미식별과 추가 시각/gain의 인과적 해결책 부재 사유는 그대로 유효하다. 이후 holdout·공식 결과로 재설계를 하지 않았다.

[당시 결정 기록](results/v2_protocol/R3_REDESIGN_DECISION.json), [나중의 R1 비교](results/v2_protocol/R3_R1_STABILITY.json)는 수정하지 않았다.

## 공식 회귀와 감지

최종 R1을 원본 기본 파일명 overlay로 A/B 한 번씩 총 58회 실행한 보존 기록이다. 공식 결과를 본 뒤 제어·가중치·임계값·선정을 바꾸거나 재실행하지 않았다.

| 방식 | 공식 8 kg RMS/최대 [mm] | 놓기 계단 [N·m] | 운반 15N/10N [ms] | 0/4/8 kg 무충돌 오감지 | 포화/발산 |
|---|---:|---:|---:|---|---|
|서보 A|1.17/3.91|14.6|45/62|0/0/0|0%/없음|
|토크 B|3.23/8.44|13.1|43/56|0/0/0|0%/없음|

개발 검증은 R1/후보 모두 A·B 15/24 검출, D4는 111/180 검출이다. 동결 뒤 한 번 연 새 holdout은 최종 R1만 검사해 A 24/30, B 22/30 검출, 정상 오감지 0/0, 편향 조건 오감지 0/1이었다. 공식 8 kg 집기 10/15N·놓기 10N 미검출과 B 운반의 충돌 밖 오감지 1회는 남았다. 이미 탈락한 후보의 holdout·공식 효능은 미실행이다.

## 계산 시간과 미달

같은 7.17 kg 관측 6000주기의 R2→R3 직렬 재생에서 토크 차이는 1.71e-13 N·m, p99는 772.189→475.509 us였다. 중복 RNE 계산·할당을 줄인 참고 이득이며 리그룹 기하만의 기여는 분리하지 못했다. 고정 순서·단일 호스트의 수치를 일반 보장으로 쓰지 않는다.

1885개 계측 episode 중 기준과 고정 진단 후보 4개 그룹만 표시했다. [7개 그룹·모든 이상치](results/v2_protocol/R3_TIMING_REVIEW.json)는 전수 보존했다. R1에는 추가 holdout·진단도 있어 행 수가 다르며 같은 조건의 속도 비로 해석하지 않는다. p99<800 us는 통과하지만 **엄격 최대 1 ms 목표는 미달**이다.

## 요구사항·검증 범위

- 최종 소스가 R1과 같으므로 가이드 33항목의 24충족/4부분/5판정 불가, 입력·형식·무결성 8통과 판정은 유지한다. G4 하중 이양·최대 1 ms·약한 힘 감지·격자 포화·섭동 오감지의 미달을 해소하지 못했다.
- 원본 29파일/보호 20파일/R2 동결 53파일/R3 동결 101파일/공식 환경 21패키지는 불변이다. 과거 R1/R2 보고서·PDF와 영상은 보존했고 새 채택이 없어 영상 재렌더는 하지 않았다.
- 전체 unittest 작업 352/공개 overlay 333, 보고서 17, 별도 함수 18회씩(일부 중복), 보고서 검사·입력 AST·공개 감사·매체·전수 SHA와 PDF 시각 검사를 확인했다. [과거 검증 기록](results/v2_protocol/R3_S6_VALIDATION.json)은 당시 시점 그대로 보존했다.
- 문서 정리는 보존 측정값의 해석·표시 수정이다. 시뮬레이션·holdout·공식 평가는 재실행하지 않았다. 실물·hidden·Windows·전역/LTV/hybrid/수동성 보장과 분석 runner·원시 trace 포함 새 수집부터의 완전 재현, Python LSP는 미검증이다.
