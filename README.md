## 결론

새 후보는 채택되지 않았고 R1을 유지했다. A STATE는 validation·development·D4·holdout과 공식 조건에서는 양의 측정값을 냈지만, 최종 제출 호환성 526개 검사에서 8개 오류가 발생해 탈락했다. 한 원소 모드 집합이 문자열로 생성되어 제어기 정보가 없는 reset에서 TypeError가 났다. 동결 뒤 수리·재평가하지 않고 미리 동결한 R1로 fallback했다. 최종 세 제출 파일은 R1과 바이트가 같다. 상세 수치와 모든 후보 행은 [R5 결과](docs/R5_RESULTS.md)에 있다. 최종 R1 fallback이면 과거 R2/R3/R4 동결 53/101/199파일 전체가 그대로다. R5 동결 목록은 119파일 중 118파일이 그대로이고, 제출 감지기 alias 한 파일만 미리 동결한 R1 fallback 바이트로 바뀌었다. runtime 62·원본 29·보호 20·환경 21 검사도 적용한다.

## 정상 전용 학습과 공개 범위

역할 수는 정상 fit 24행, 정상 calibration 16행, 정상 audit 16행이다. fit은 가중치 학습, calibration은 정상 임계값 고정, audit은 학습 뒤 무충돌 확인이다. 충돌 라벨·내부 물리값·별도 평가 자료는 학습이나 임계값 선택에 쓰지 않았다. SCALE_STATE는 방식별 263개 부동소수 파라미터를 가진다. 원인 자료에서 R1은 A 54/B 52건을 검출했고, 힘 구간에서 gate 꺼짐은 A 20/B 23건, 활성 중 임계 미만은 A 16/B 15건이었다. STATE의 경험적 추가 검출은 각 +6(집기 2·운반 4·놓기 0)이지만 형식적 상한이나 단일 물리 원인으로 해석하지 않는다. 비공개 취득·sealed 실행 드라이버와 raw 신호는 배포하지 않고, 안전한 runtime/build/정상 재학습/scoring/result 파일만 제공한다.
