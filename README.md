# 팔레타이징 하중 이양 · 순차 충돌 감지 R4

A=서보, B=토크, FA=오감지다. 기준=배포 키트, v1=탄성·하중 이양 제어와 기하 감지,
R1=v1 제어와 정상-only ridge/EMA 감지, R4=고정 정상 보정 순차 감지의 최종 판정이다.

**새 채택 0개, 최종 3파일은 R1과 바이트가 같다. 수정 W40은 D4에서 A +13, B +10 검출했지만 무충돌 섭동 FA가 A 6→9, B 9→17로 늘어 탈락했다. 모든 후보는 동결 전에 탈락했고 새 holdout은 R1 보존만 확인했다.**

## 용어

- W40은 현재까지의 40 ms 후행 평균으로 짧은 오차를 모아 보는 감지 방법이다.
- CUSUM은 정상 수준보다 큰 오차를 시간에 따라 누적하는 변화 감지 방법이다.
- D4는 질량·무게중심·외력을 넓힌 기존 개발 평가로, 방식당 385조건 중 충돌은 180조건이다.
- holdout은 후보 선정에 쓰지 않고 마지막에 한 번 확인하는 별도 평가 자료다.
- 동결은 별도 평가 전에 코드·보정값·최종 선택을 고정하는 절차다.

## 구현에서 발견한 문제와 수정

처음 만든 감지기는 기존 모델의 임시값을 같은 값으로 다시 저장했다. 물리 결과는 같았지만 공유 상태에 쓰지 말라는 규칙을 어겼다. 당시 W40은 추가 검출 A 4/B 3건과 정상 오감지 보존을 보여, 이 방법만 재설계 1회를 써 중복 저장을 없앴다. 가중치·통계량·임계값은 그대로다. 새 조건의 재검증에서 추가 검출은 A 4/B 4건이었다. CUSUM 3설정은 고치지 않았고 계속 탈락이다.

[공유 임시값과 재설계의 세부 설명](docs/R4_METHODS.md#비간섭과-안정성의-범위)을 따로 적었다.

## 별도 평가 조건을 미리 만든 사고와 조치

검사 코드의 실수로 원래 별도 평가 시드 371501의 조건을 동결 전에 메모리에서 두 번 만들었다. 조건을 출력·저장하거나 시뮬레이션을 실행하지는 않았지만 사전 생성 금지 위반으로 기록했다. 후보 충돌 결과를 보기 전에 그 시드를 폐기하고 새 시드 371599로 바꿨다. 관문과 조건 범위는 그대로다. 실제 새 holdout은 코드와 선택을 동결하고 실행 시작을 한 번만 기록한 뒤 1회 진행했다. 재검증에서 쓴 질량 1.5173, 3.8051, 6.0473, 7.2303 kg은 동결 전에 새 별도 평가의 제외 목록에 추가했다.

## 계산 시간과 미달

| 방식·소스 | 최악 행 p99 [µs] | 관측 최대 [ms] | 1 ms 초과 주기 |
|---|---|---|---|
| A 서보/R1 | 260.611 | 0.501 | 0 |
| A 서보/W40 | 342.133 | 5.141 | 1 |
| B 토크/R1 | 307.692 | 5.257 | 3 |
| B 토크/W40 | 275.261 | 0.466 | 0 |

같은 새 사전 재검증 38조건/방식의 제어기+감지기 합산 벽시계 시간이다. 각 소스는 228,000주기이며, p99는 주기 시간의 99백분위값 중 가장 나쁜 조건의 값이다. p99 800 µs 관문은 통과했지만 A W40·B R1의 관측 최대 1 ms 목표는 미달이다. 직렬 실행 순서와 OS 부하의 영향이 있어 순수 알고리즘 속도 비나 시간 상한 보장으로 쓰지 않는다.

**보존된 R3 표:** 서보 R1은 p99 327.670 µs, 최대 11.703 ms, 1 ms 초과 8주기다. 토크 R1은 p99 350.440 µs, 최대 14.163 ms, 1 ms 초과 4주기다. **R1은 최대 1 ms 목표 미달이다.** R3 표의 원래 표시값을 그대로 인용했으며 재계측하지 않았다. 위 38조건 표와 평가 범위가 다르고 이 유한 표로 과거 미달이 해소됐다고 주장하지 않는다. [보존된 R3 시간 표](docs/R3_README.md#계산-시간과-미달)를 함께 본다.

- G4 지속 지지(평균 ≥50 %mg, 최소 ≥25 %mg, v1 대비 +25 %p, 놓기 힘 ≤1.1 mg)는 완화하지 않았고 미달이다.
- 공식 8 kg 집기 10·15 N과 놓기 10 N 미검출, 보존 무충돌 격자의 서보 포화 2/189조건, R1 섭동 FA A 6/B 9가 남는다.
- 수정 W40도 섭동 FA 증가로 탈락했다. 새 방법의 전체 우위·실기 안전·엄격 최대 1 ms를 주장하지 않는다.

## 요구사항 점검

기존 가이드 33항목의 24충족/4부분/5판정 불가와 입력·형식·무결성 8통과 판정은 최종 3파일이 R1과 같아 유지한다. 이는 모든 성능 목표의 충족이나 새 후보의 성공을 뜻하지 않는다. 판정 불가에는 선택하지 않은 권고 항목과 비공개 평가도 포함된다. [가이드 요구와 자체 목표의 구분](docs/REQUIREMENTS_AUDIT.md)을 보존했다.

## 이번에 시도하지 않은 것

- 토크 추적 feedforward는 구현하지 않았고 효과는 모른다. 감지기의 추가 검출 여지를 먼저 시험해 2순위로 남겼다.
- 공식 8 kg 미검출 3조건에 W40을 실행하지 않았다. 집기 10·15 N과 놓기 10 N은 최종 R1의 미검출이며 W40의 개선 여부는 모른다.

문헌 10편을 직접 확인해 순차 누적과 고정 정상 보정을 골랐다. 온라인 ACI/AgACI,
RL, 리그룹 재시도는 이번 후보에서 제외했다. 자세한 확인 범위와
논문에서 바꾼 점은 방법·문헌 문서에 구분했다.
