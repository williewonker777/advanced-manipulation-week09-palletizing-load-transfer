## 결론

S1 결과 직렬화 실패로 R6 후보를 채택하지 않고 A 서보와 B 토크 모두 R1을 유지했다. holdout과 공식 평가는 열지 않았다. 결함은 한 원소 모드 집합이 문자열로 만들어진 것이며, 이를 `('servo',)` 튜플로 고쳤다. 모델 263개 파라미터, 임계값, R1 제어기와 모든 관문 숫자는 바꾸지 않았다. 초기 전체 534개와 최종 동결 전 전체 592개, 기본 이름 8개 검사가 통과했다. 새 full-loop 8회는 모두 완료됐고 사후 raw 검토에서 물리·packet·결정 비트가 같았다. 그러나 결과 직렬화가 실패했으므로 이 사후 검토는 실패한 S1 transaction을 수리하거나 통과로 바꾸지 않는다. 상세 근거는 [R6 결과](docs/R6_RESULTS.md), 방법은 [R6 방법](docs/R6_METHODS.md), 발표 자료는 [PDF](results/presentation.pdf)에 있다.

## 미달과 범위

- 새 holdout 계산 시간은 미실행이다. 최대 1 ms를 보장으로 주장하지 않는다.
- 무충돌 섭동 28 reference FA는 A 6→6, B 9→9다.
- 전체 34조건 FA는 A 6→6, B 10→10다. 28 reference 범위와 섞지 않는다.
- 탈락한 B STATE 진단값은 D4 추가 +5로 기준 6에 못 미쳤고, 28 reference FA가 9→10로 늘었다. R6 B에는 승계하지 않았다.
- 놓기 전 평균 지지율은 R1에서 A 0.2098; B 11.1507로 50 %mg 기준에 못 미친다.
- D4 R1 포화/놓기 peak는 A sat 2/189, peak 1.6098 mg; B sat 0/189, peak 1.0358 mg로 A 포화 0회와 peak 1.1 mg 기준을 만족하지 못한다.
- 유한 시뮬레이션 결과이며 하드웨어 안전 보장이나 충돌 정지 인증이 아니다.
