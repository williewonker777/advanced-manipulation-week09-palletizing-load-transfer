# 팔레타이징 하중 이양: 탄성 관절 제어와 충돌 감지 (Week09 최종)

M1013 팔레타이징 시뮬레이션의 1 ms 제어 주기에서 박스를 작업대에 내려놓는 과제입니다. 감속기 처짐과 수십 ms에 걸친 하중 이양을 제어에 반영하고, 정상적인 하중 변화와 실제 충돌을 구분해 감지해야 합니다. 서보(A)와 토크(B) 두 제어 방식을 모두 다룹니다.

> 이 저장소에는 **직접 작성한 코드와 결과만** 있습니다. 수업 키트의 `sim/`, `model/`, 기준 제어기·감지기, 실행기와 평가기는 포함하지 않습니다.

## 무엇을 바꿨나

### 제어 (v1부터 최종까지 동일)

- **서보 A (`my_servo.py`):** 감속기 처짐과 하중 이양을 반영해 관절 지령을 만듭니다. 시뮬레이터에 명시된 1주기 지령 지연도 보상합니다.
- **토크 B (`my_torque.py`):** 관절 토크 센서 피드백을 제한한 탄성 관절 모터 PD입니다.
- **공유 추정기:** 두 제어기는 감지기와 같은 추정기를 공유합니다. 이 추정기는 엔코더와 관절 토크 센서만으로 외력과 하중 이양을 추정합니다.

### 충돌 감지 (`my_detector.py`)

감지기는 연결된 제어기를 보고 `reset()`에서 방식을 한 번 고릅니다. 1 ms 루프에서는 분기하지 않습니다.

| 제어기 | 감지 방식 | 내용 |
|---|---|---|
| 제공한 토크 제어기 | **R31** | R10에 두 관측을 더했습니다. 기저축 외부 회전 모멘트 추정(R21)과, 집기·놓기 구간의 수평력 관측(R22–R23)입니다. 같은 충격에 경보가 여러 번 울리는 문제는 R24–R31에서 줄였습니다. |
| 제공한 서보 제어기 | **R32** | R10에 지연 수평력 관측을 더했습니다(놓기 직전의 약한 충돌이 목표). 두 관측기의 수평력이 같은 방향일 때만 알리고, 둘 다 안정된 뒤에야 다시 무장합니다. |
| 그 밖의 제어기 | R10 | 공유 추정기의 외력 잔차를 작업대 지지 방향까지 고려해 방향·지속 조건으로 판정합니다. |

연구 단계 코드와 정상 동작 모델 수치를 그대로 한 파일에 연결했고, 새 검출 규칙이나 문턱 조정은 없습니다. 조합 방식과 검증은 [최종 제출본 문서](docs/FINAL_SUBMISSION.md)에 있습니다.

### 남은 과제

1. **하중 이양:** 놓기 전 지속 지지(G4)를 충돌 보호와 동시에 만족하는 제어.
2. **다방향·약한 충돌:** 놓은 뒤의 사선 충격, 짧은 간격의 연속 충격, 실제 공구 접촉을 오경보 없이 구분.
3. **최대 1 ms:** 실행 환경 격리와 계산 경량화를 함께 검토한 뒤 대상 환경에서 다시 측정.
4. **서보 포화와 섭동 오감지:** 원인 조건을 식별한 뒤 완화.

## 실행과 재현

수업 키트 폴더(`icpbl_sim`)에 `submission/`의 세 파일을 복사한 뒤 원본 평가기를 실행합니다.

```bash
python evaluate.py --ctrl my_servo --detector my_detector
python evaluate.py --ctrl my_torque --detector my_detector
```

- 최종본 재빌드와 공식 검증: [docs/FINAL_SUBMISSION.md](docs/FINAL_SUBMISSION.md#재현)
- 루트의 `my_servo.py`, `my_torque.py`, `my_detector.py`는 연구 후보들이 상속하는 R10 기준본입니다. R10 검사 방법은 [R10 제출 판정](docs/R10_RELEASE.md)에 있습니다.
