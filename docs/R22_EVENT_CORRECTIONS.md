# R22: 한 표본의 오경보와 놓을 때의 중복 경보

이 문서의 충돌 수는 **시뮬레이션** 결과다. 제공 프로그램·기본 제어기·기본 감지기로 실행한 [수업 원본 데모](DEMO_SOURCES.md), R10 기본 제출본, R22 연구용 감지기를 구분한다. R22 충돌 비교에서는 명시하지 않는 한 R10 토크 제어기의 물리 동작은 바꾸지 않았다.

## 같은 경보처럼 보인 두 가지 문제

- **8 kg 무충돌, 1.709 s:** 무게중심 Z가 −2 cm인 조건에서 수평 힘 Y 추정이 한 표본만 −18.734 N이 됐다. R20에서 물려받은 18.375 N 한계를 넘었고, R10과 회전 감지기 자체는 울리지 않았다. 전체 한계를 올리는 대신 수평력의 각 성분에 과거 세 표본의 중앙값을 썼다. 주기적인 힘의 부호를 보존하되 고립된 한 표본은 결정을 바꾸지 않는다.
- **놓기 경계:** 집게가 열릴 때 각운동량 이력을 비우면 아직 끝나지 않은 충격이 46 ms 뒤에 새로운 충격처럼 보일 수 있다. 반대로 항상 이력을 잇는 것도 옳지 않았다. 원래의 330·339·349번 중복을 없앴지만, 319·335번에는 새 중복이 생겼다. 물체가 분리되기 **직전 표본의 센서 경보**가 이미 켜져 있었을 때만 추정한 반출 각운동량을 빼고 이력을 보존하는 방식을 별도로 만들었다. 조용하던 양의 질량이 분리되면 미확인 잔차를 넘기지 않고 새로 관측한다. 빈 집게는 실제 반출 질량이 없어 이력을 보존한다. 충돌 시각·정답·경과시간에 맞춘 재경보 금지 타이머는 쓰지 않는다.

## 6 N과 6.5 N을 잡았다고 전체 센서를 켜 두지 않은 이유

엔코더·관절 토크센서의 지연을 보정해 얻은 월드 수평 힘을 12표본 평균한 뒤 판정했다. 정상 32회만으로 고정한 전 구간 한계는 무하중 4.60 N, 가벼운 파지 5.39 N, 중간 파지 5.59 N, 무거운 파지 11.84 N이었다. 이 신호를 어디서나 기존 감지기와 함께 쓰면 이전에 놓친 6 N과 6.5 N을 41/45 ms에 찾지만, 전체 D4에서는 **28조건에서 보호 검사 실패**가 생겼다. 특히 앞선 충격 뒤 정상적인 착지 동작을 새 충돌로 판정했다.

별도 후보에서는 기존 감지기를 모든 질량·동작에서 유지하되, 추가 수평력 신호는 **물체 무게가 목표 10 N 이하인 초기 들어올림 동작**에서만 받아들인다. 즉 8 kg에서 충돌 감지를 끄는 것이 아니다. 무거운 물체나 내려놓기에서는 기본 관측이 계속되고, 이 보조 측정만 충돌 근거로 쓰지 않는다. 가벼운 물체에서도 표면 마찰·동적 접촉을 엄밀히 제한하는 방법은 아니므로 별도 시험이 필요하다. 한계값을 낮추거나 이미 본 두 충격을 미사용 조건으로 다시 세지 않았다.

## 같은 385조건에서 비교한 결과

아래 D4는 189개 정상 기준 동작, 180개 단일 충격, 16개 오프셋을 포함하는 **이미 알려진 개발 세트**다. 각 충격은 같은 질량·무게중심의 무충돌 실행과 대조했다. 원본 순서로 계산한 표본별 힘의 크기, 부호 있는 벡터, 첫 실제 외력 직전까지의 상태·경보, 감지기 간 물리 궤적을 대조했다. 감지기별 판정과 힘 입력 검증 실패를 따로 기록한다.

| 토크 감지기 | 구별한 충돌 / 180 | 전체 오경보 상승 | 한 충격 안의 귀속 가능한 중복 상승 | R22 보호 검사 실패 조건 |
|---|---:|---:|---:|---:|
| R10 기본 제출 | 111 | 9 | 3 | 비교 기준 |
| R21 연구 옵션 | 136 | 10 | 6 | [R21에서 확인한 실제 회귀 4개](../experiments/r21_full_protection/summary.json) |
| R22 중앙값 + 항상 이력 보존 | 137 | 9 | 4 | 2 |
| 위 조합 + 수평력 신호 전 구간 사용 | 153 | 22 | 17 | 28 |
| 직전 경보에 따라 놓기 이력 선택 | 136 | 9 | 2 | 0 |
| **선택한 연구 후보: 이력 선택 + 경량 들어올림 신호** | 137 | 9 | 2 | 0 |

여기서 ‘보호 검사’는 전체 검출 수만 비교하지 않는다. R10과 R21이 구별했던 충격과 실제 공구 접촉을 잃지 않는지, 기존보다 오경보·중복·사전 경보가 늘거나 마지막까지 경보가 남는 조건이 있는지를 **조건별로** 본다. 선택 후보는 기존 공구 접촉 6건을 모두 보존했다. 전체 오경보 9회와 중복 2회가 남아 있으므로 ‘충돌을 모두 해결했다’는 뜻은 아니다. [조건별 D4 판정·입력 근거](../results/r22/d4.json).

## 공식표·기존 약충격·진짜 두 번째 충격

- **수업 공식 평가기:** R10 토크 **18/24**, R21 및 R22 선택 후보 **24/24**. R22의 10 N은 집기 직후 0/8 kg에서 **38/43 ms**, 놓기 직전 **49/91 ms**였다. 정상 0·4·8 kg의 오경보는 각각 0회, 충돌 중인 실행에 남은 다른 오경보 최댓값은 1회다. [수치와 제어표](../results/r22/official_torque.json).
- **이전에 공개된 약충격 12개:** R10/R21/선택 후보 **8/10/12건**. +X 6 N은 41 ms, +Y 6.5 N은 45 ms였다. 이것은 R21 당시에는 미사용 조건이었지만, R22에서는 이미 본 실패의 재검증이다. [각 충격과 무충격 대조](../results/r22/exposed_weak.json).
- **서로 다른 충격:** ‘없음·첫째만·둘째만·둘 다’를 기본/변경 작업대에서 실행했다. R21의 기존 표면 4/8 → R22 **8/8**, 과거 별도로 열었던 세 쌍은 양쪽 모두 **4/6**. 7.13 kg에서 136 ms 떨어진 충격은 두 상승이 분리되어도, 둘째 시작 전 20 ms의 경보 정숙 조건을 충족하지 않아 성공으로 세지 않았다. [모든 짝 실험](../results/r22/known_pairs.json).
- [미사용 시험 결과를 열기 전에 선택한 근거](../results/r22/selection.json). 전체 D4와 기존 약충격을 동시에 통과한 이유로 경량 보조 방식을 선택했다. 이 선택 자체가 미사용 조건을 통과했다는 뜻은 아니다.

## 선택 뒤 처음 공개한 독립 시험: 미통과

후보 선택에 사용한 385조건과 별개다. 시험 담당자가 충격과 대조 조건을 미리 정하고, 개발자는 그 답을 보기 전에 경량 후보의 소스와 선택 사유를 고정했다. 원본 물성, 접촉·흡착 물성 변경, 구동기 이득 변경을 나누고 세 감지기를 비교했다. **후보 하나당 총 486회**이며, 한 번의 실행을 서로 독립적인 6,000개 시험으로 세지 않았다. 입력 힘·운동 궤적·충격 전 이력 검증은 통과했다. 이는 감지 성능의 통과와 다르다. 배포 사본에서 독립적으로 다시 실행한 486회의 결과는 최초 봉인 해제 때의 결과와 바이트 단위로 같았다. 사후에 구조 검사를 강화했지만 처음의 미통과 판정이나 평가 알고리즘을 고치지는 않았다.

| 독립 시험 | R10 | R21 | 선택 R22 |
|---|---:|---:|---:|
| 외력을 주지 않은 대조군 18조건의 거짓 경보 상승 | 0 | 0 | 0 |
| 단일 충격에서 정확히 한 번 / 24조건 | 9 | 18 | 18 |
| 이중 충격의 개별 판정 / 96개 | 48 | 79 | 79 |
| 개별 판정 네 개를 모두 만족한 이중 충격 / 24조건 | 6 | 15 | 15 |

따라서 **66조건 중 15개 미통과**다. R21이 성공했던 충격을 잃지는 않았지만, 새로 성공한 독립 조건도 없었다. 예를 들어 4.83 kg 상자를 놓은 뒤 3.927 s에 가한 수평 사선 힘 (−7.7, −7.1) N, 크기 약 10.47 N은 세 물성 모두 놓쳤다. 공식 10 N 성공만으로 놓은 뒤의 충격까지 검출한다고 말할 수 없는 구체적인 반례다. 집기 때의 근접 사선 쌍, 놓기 때의 짧은 간격 쌍, 놓기 경계를 지나는 쌍도 세 물성 모두에서 엄격 판정에 실패했다. 무외력 오프셋 중 두 조건에는 실제 공구 접촉이 있었지만 **세 감지기가 모두 놓쳤다**. 개발 세트에서 공구 접촉 6개를 보존한 사실을 이 시험에 일반화할 수 없다. 거짓 경보 0회는 접촉을 모두 찾았다는 뜻이 아니다. [선택 R22의 15개 실패와 판정 시점](../results/r22/holdout_selected.json).

전 구간에 수평력 보조를 사용했던 탈락 후보도 같은 시험으로 남겼다. 단일은 21/24였지만 이중 판정은 78/96, 네 판정 전부 성공은 14/24였고 추가 오경보도 있어 66조건 중 14개 미통과였다. 두 후보 중 성적이 나아 보이는 항목만 다시 골라 기본본으로 채택하지 않았다. [탈락 후보의 독립 결과](../results/r22/holdout_augmented.json).

## 다른 한계: 하중 이양과 연산 시간

- **실제 하중 이양:** 별도의 제어 실험에서 마지막 20 ms 동안 평균 지지력은 물체 무게의 61.9%, 최소 47.9%, 최대 103.9%였고 정한 지지 기준 네 개를 충족했다. 그러나 같은 무충돌 동작의 3.903 s에 여전히 경보가 울렸다. 원인은 수평축 주위의 모멘트(My)였고, R22가 보정하는 수직축 회전 모멘트(Mz)와 다르다. R22는 제어 명령을 바꾸지 않으며 이 문제를 해결한 것으로 세지 않는다. [센서·제어 분리 실험](../results/r22/payload_boundary.json).
- **처리 시간:** 같은 실제 제어+감지 호출을 조건 세 개, 순서를 바꾼 두 반복으로 측정했다. 두 번째 측정의 에피소드별 벽시계 p99 최댓값은 R10/R21/이력선택/선택 R22 각각 291/326/326/336 µs. 선택 R22는 36,000주기 중 1 ms 이상 0회였지만, 부하가 달랐던 첫 측정에서는 공통 비교군도 1 ms를 초과했다. 서로 다른 부하에서의 숫자로 속도 우위나 1 ms 마감 보장을 주장하지 않는다. [벽시계·스레드 CPU 원자료 요약](../results/r22/timing.json).

## 직접 재현하기

먼저 원본 키트를 별도로 준비하고, 현재 디렉터리를 이 저장소의 최상위로 둔다. 아래에서 `KIT`는 수업의 **수정하지 않은** `icpbl_sim`, `GUIDE`는 같은 배포본의 HTML 실습 가이드, `OUT`은 저장소·키트 밖에 있는 **이미 만들어 둔 결과 디렉터리**다. 각 명령에는 아직 존재하지 않는 결과 이름을 준다. 수업 시뮬레이터 의존성이 설치된 Python 환경을 활성화한 뒤 실행한다. 원본 키트를 덮어쓰지 않으며 원격 업로드도 하지 않는다.

```sh
# 1. R22가 아닌 수업 기본 서보 예제: 가이드 그림과 바이트 비교
python -B tools/course_example.py --kit "$KIT" --guide "$GUIDE" --out "$OUT/course-demo"

# 2. 지정한 연구 후보의 두 코드 파일을 담은 선택형 ZIP (인증된 원본 공식 평가 포함)
python -B tools/r22_torque_package.py --kit "$KIT" --variant light --out "$OUT/week09-r22-light.zip"

# 3. 알려진 약충격 및 전체 D4. full은 R10·R21·R22를 새로 385회씩 시뮬레이션한다.
python -B tools/r22_studies.py --kit "$KIT" --revised --study weak --out "$OUT/weak.json"
python -B tools/r22_census.py --kit "$KIT" --policy light --cohort full --workers 3 --out "$OUT/d4.json"

# 4. 이제는 공개된 독립 시험: 선택 당시의 소스 잠금으로 실패까지 그대로 재현
python -B -m tools.r22_challenge_replay --kit "$KIT" --lock results/r22/holdout_selected.lock.json --jobs 2 --out "$OUT/independent"
```

전 구간 후보의 미통과 결과도 마지막 명령에서 잠금 파일을 [전 구간 후보 소스 잠금](../results/r22/holdout_augmented.lock.json)으로, 출력 위치를 새 디렉터리로 바꾸면 재현할 수 있다.

[배포 사본의 재실행 기록](../results/r22/reproduction.json)에는 원본 예제, 기존 약충격, 전체 D4, 미통과 독립 시험의 해시가 있다. [ZIP 명세와 SHA-256](../results/r22/package.json) · [원본 평가기·단일 파일 대조](../results/r22/standalone.json).

연구 ZIP은 수업 원본이나 기본 제출물이 아니다. 기본 세 파일은 R10으로 유지하며, 독립 시험과 하중 이양에 미해결 항목이 남아 있다. 실기 동작이나 안전 인증을 검증하지 않았다.
