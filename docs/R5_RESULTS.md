# R5 결과

A=서보, B=토크, FA=오감지다.

## 결론

새 후보는 채택되지 않았고 R1을 유지했다. A STATE는 validation·development·D4·holdout과 공식 조건에서는 양의 측정값을 냈지만, 최종 제출 호환성 526개 검사에서 8개 오류가 발생해 탈락했다. 한 원소 모드 집합이 문자열로 생성되어 제어기 정보가 없는 reset에서 TypeError가 났다. 동결 뒤 수리·재평가하지 않고 미리 동결한 R1로 fallback했다. 최종 세 제출 파일은 R1과 바이트가 같다. A STATE 잠정 판정 때 만든 비교 영상 두 쌍은 최종 탈락 뒤 보관 전용으로 옮겼고 공개 결과에는 넣지 않았다.

## 재설계

재설계 0회. SCALE: 상태 정규화의 validation 관문 통과 여부와 위상 대조의 실패를 그대로 보존한다. 수식 대조·물리8배열·온라인/오프라인 대응에서 구현 결함은 발견되지 않았다. 통과한 방식은 변경할 이유가 없으며, 실패한 대조를 충돌 임계 조절로 되살리지 않는다. AR: S2에서 충돌 외 오감지가 증가해 이미 영구 진단으로 고정됐다. validation에서도 조건별 오감지 증가를 기록했지만 수식/물리 대응 결함은 발견되지 않았다. 식별된 구현 결함 없이 격자나 임계를 조절하는 재설계는 하지 않는다. [당시 결정](../results/v2_protocol/R5_REDESIGN_DECISION.json)을 그대로 보존한다.

## 무결성

최종 R1 fallback이면 과거 R2/R3/R4 동결 53/101/199파일 전체가 그대로다. R5 동결 목록은 119파일 중 118파일이 그대로이고, 제출 감지기 alias 한 파일만 미리 동결한 R1 fallback 바이트로 바뀌었다. runtime 62·원본 29·보호 20·환경 21 검사도 적용한다.
