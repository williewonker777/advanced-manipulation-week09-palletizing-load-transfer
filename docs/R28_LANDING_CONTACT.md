# R28: 하중을 내려놓을 때의 경보와 진짜 집기 충격 구분

**[수업 원본 8 kg 데모](DEMO_SOURCES.md)가 아니다.** 같은 G4 착지 제어기에서 경보만 비교한 MuJoCo 3.17.0 실험이다. [R27의 실제 공구 접촉](R27_G4_INTEGRATION.md)은 그대로 잡으면서, 약 2.5초 뒤 울린 네 오경보를 없애는 것이 목표다.

## 같은 두 현상을 구별해야 하는 이유

1. **5.25 kg · 위로 29 mm 어긋난 공구.** 진짜 접촉은 1.083–1.399초였고 기존 감지기는 +10 ms에 잡았다. 문제의 네 추가 경보(3.858/3.878/3.880/3.884초)에는 더 이상 공구력이나 가한 외력이 없었다. 단순히 보류 중인 알림의 재시작을 막으면 뒤 세 개는 사라지지만 첫 번째는 남는다.
2. **8 kg · 집기 중 실제 +Y 15 N.** 작업대가 하중을 받는 순간에 추가 경보를 금지하고 이전 정상 상태까지 모두 지우면 위 오경보 네 개는 사라진다. 하지만 집기 중 1.456초의 짧은 수직 반력(1.62 N)에도 정상 힘을 봤다는 기록이 지워진다. 실제 충격을 구별하던 1.463–1.464초에는 작업대 수직 반력이 0 N이었지만, 재준비에 필요한 낮은 힘을 다시 관측하지 못해 **8 kg 충격을 놓쳤다**. 센서가 NaN일 때 0 N으로 잘못 처리하던 별도 수치 오류도 수정했다. 이 수정만으로는 놓친 충격이 돌아오지 않았다.

**서로 다른 상태 두 개를 분리했다.** ‘직전에 힘이 낮았음을 실제로 관측했다’는 정보는 남긴다. 반면 ‘지금 경보를 시작·유지해도 된다’는 판단은 하중을 팔이 지지하고 작업대가 유의미한 하중을 받지 않을 때만 유효하다. 그 판단이 끊기면 연속 검출 횟수와 남은 알림을 이어 쓰지 않는다. 기존 C1 경보는 어느 경우에도 차단하지 않는다. 판정에 실험 시간이나 정답 외력 방향을 쓰지 않았고, 이미 고정한 힘 상한·연속 표본 수·센서 분해능도 바꾸지 않았다.

## 같은 감지기로 두 목표를 모두 확인한 결과

이미 공개된 조건을 **46회** 다시 돌렸다. 최종 후속 방식은 5.25 kg 공구 조건에서 R27이 더했던 **네 오경보를 모두 제거**했다. 진짜 공구 접촉은 여전히 **+10 ms**, 0/8 kg 집기 충격도 각각 **+38/+43 ms**에 잡았다. 원래 C1에도 있던 3.903/3.923초의 오경보 두 번은 남았다. 해당 공구 에피소드의 경보 활성 표본 수는 **214→207**로 C1과 같았다. 단순히 모든 경보를 끄거나 힘이 가해진 시각을 입력으로 주어 얻은 결과가 아니다. 같은 물리·실제 외력에서 기존 C1 경보 15개가 유지된 것도 확인했다.

| 방식 | 5.25 kg에서 C1보다 **추가된** 뒤늦은 오경보 | 0 kg +Y 15 N | 8 kg +Y 15 N |
|---|---:|---:|---:|
| 기존 C1 | 기준 | 미검출 | 미검출 |
| R27 V3 | 4회 | +38 ms | +43 ms |
| 보류 알림의 재시작만 취소한 대조 | 1회 | +38 ms | +43 ms |
| 접촉 때 정상 관측 기억도 지움 | 0회 | +38 ms | 미검출 |
| **정상 관측 기억 보존** | **0회** | **+38 ms** | **+43 ms** |

경량 0.1–1.0 kg의 정·역방향 패널 **24회**, 놓은 뒤 X/Z 충격 **10회**, 집기 방향·연속 충격 패널 **20회**에서도 V3 대비 보호 기준을 지켰다. 앞의 46회를 포함한 **총 100회는 모두 이미 알려진 조건**이다. 수직 집기처럼 V3에서 이미 놓치던 경우까지 해결했다는 뜻은 아니다.

## 실제 공식 평가 결과

같은 원본 평가기로 각 방식 29회, 총 **116회** 실행했다. 아래 분모 24는 공식 수평 충격 수다. 제어표와 공식 오경보 수는 네 방식에서 같았다. 무충격 오경보 1회와 충격 실행 중 최대 오경보 2회는 남아 있다.

| 같은 착지 제어에 연결한 감지기 | 공식 수평 충격 | 두드러진 차이 |
|---|---:|---|
| 기존 C1 | 15/24 | 0 kg과 8 kg의 +Y 15 N을 놓침 |
| R27 하중 분해능 방식(V3) | 17/24 | 두 집기 충격은 잡지만 공구 접촉 뒤 오경보 4회가 추가됨 |
| 접촉 때 정상 관측 기억도 지움 | 16/24 | 오경보 4회 제거, 8 kg 실제 충격 미검출 |
| **정상 관측 기억을 보존** | **17/24** | 정상 힘 관측과 알림 수명을 분리한 공개 후속 실험 |

표의 +38/+43 ms는 무게중심을 중앙에 둔 힘/무입력 짝에서 **실제 첫 비영 외력**부터 센 값이다. 공식 설정은 기본 무게중심을 쓰고 공칭 시작 시각부터 집계한다. 공식 15 N 집기 칸은 0/8 kg 모두 39 ms였다. 검출 수가 같다고 모든 지연까지 같지는 않다. V3 대비 8 kg의 40/100 N 집기 지연은 28→33 / 21→24 ms, 100 N 놓기 지연은 25→27 ms였다. 나머지 공식 충격 표 셀은 같았다.

이 **17/24는 기본 제출 R10의 토크 18/24를 대체하지 않는다**. 처음 등록한 엄격한 후보는 8 kg 보호 조건에서 탈락했다. 별도로 고정한 착지 신규 19조건은 비교 기준 C1만 실행했고, 새 후보는 **0회·미채점**이다. 이미 알려진 8 kg 실패를 보고 만든 마지막 방식도 그 시험에 넣지 않았다. 기본 토크 제어의 별도 114회 시험 역시 미개봉이며, 둘은 서로 다른 시험이다. [실측 결과와 미등록 기록](../results/r28/summary.json)

## 원본과 연구 재생

```bash
KIT=/path/to/icpbl_sim
OUT=$(mktemp -d)
# 고하중 공구, 무접촉 대조, 0/8 kg 실제 +Y 충격: 네 조합으로 24회
python -B tools/r28_memory_cases.py compare --kit "$KIT" --out "$OUT/known-cases"
# 위 조건만 재생하는 소스 ZIP
python -B tools/r28_memory_cases.py build-zip --out "$OUT/week09-r28-memory-cases.zip"
# 연구: 같은 착지 제어에서 네 감지기를 원본 채점기로 각각 29회 실행
python -B tools/r28_contact_memory.py official --kit "$KIT" --out "$OUT/four-arms"
# 비교용 키트 미포함 ZIP을 생성할 때
python -B tools/r28_contact_memory.py build-zip --out "$OUT/week09-r28-contact-memory.zip"
```

출력은 반드시 새 경로를 쓴다. 연구용 ZIP은 수업 키트·채점기·원본 그림을 포함하지 않는다. 설치한 원본 키트의 파일을 인증한 뒤 별도 임시 사본에서만 실행한다. 수업 원본을 보고 싶다면 연구 명령 대신 **제공 서보/제공 감지기의 `run.py --box 8`**을 사용한다.

[세 연구 ZIP의 지문·원본 미포함 검증·압축 해제본 재생 결과](../results/r28/reproducibility.json). 네 감지기 공식 재생은 모든 과학적 결과가 같았고, 벽시계 출력에 따른 네 stdout 지문만 달랐다.
