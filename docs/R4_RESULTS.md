## 원인 분석과 경험적 상한

R1 D4 놓침 중 높이 조건 때문에 학습 분기가 외력 전체에서 꺼진 경우는 A 43개, B 46개였다. 이는 그 분기가 쓰이지 못한 이유이지, 전체 감지기 실패의 단독 원인이라는 증명은 아니다.

놓침 69건 중 A 52건, B 53건은 7개 진단 점수 모두의 평가창 최댓값이 각각 정상 189조건의 전역 최댓값 이하였다. 진단 코드의 한 부동소수 간격 높은 경계를 넘지 않은 경우를 원자료와도 대조했다. 경계 설정과 성능 확인에 같은 자료를 쓴 비독립 진단이므로, 일반화 한계나 모든 허용 신호의 원리적 구분 불가능성을 증명하지 않는다.

같은 개발 자료의 정상 최대 경계에서 40 ms 평균은 추가 17/15개(A/B), 4연속 조건은 13/14개를 분리했다. 같은 자료를 쓴 진단 상한이라 독립 효능이나 일반화 보장이 아니다.

## 문헌과 후보

기존 목록과 겹치지 않는 10편을 확인했다. 원문 7편, 기관 초록·서지 2편, 출판 서지 1편이다. W40과 고정 CUSUM을 구현했고 온라인 적응 보정·RL·리그룹 재시도는 제외했다.

## 정상 보정·비간섭

무충돌 검사 128행에서 추가 경보 표본 0개, 경보 시작 0개였다. 기존 R1 전체 경보를 0으로 가정한 것이 아니라 새 분기의 추가 경보만 분리해 검사했다.

감지기 변경 전후 제어·물리값 일치 기록은 16행이며 결과는 통과다. 새 W40 대표 4행과 변경 없는 CUSUM의 기존 12행을 합쳤다. 16행 전부가 새 실행은 아니다. W40은 별도로 새 76조건의 전체 시뮬레이션에서 물리 배열과 감지 판정을 대조했고, 최초 후보 304행 기록도 보존했다. CUSUM은 수치가 같아도 공유 임시값을 다시 저장해 쓰기 금지 규칙을 어겼으므로 계속 탈락이다.

### 공유 임시값을 다시 저장한 문제와 수정

처음 만든 감지기는 기존 모델의 임시값을 같은 값으로 다시 저장했다. 물리 결과는 같았지만 공유 상태에 쓰지 말라는 규칙을 어겼다. 당시 W40은 추가 검출 A 4/B 3건과 정상 오감지 보존을 보여, 이 방법만 재설계 1회를 써 중복 저장을 없앴다. 가중치·통계량·임계값은 그대로다. 새 조건의 재검증에서 추가 검출은 A 4/B 4건이었다. CUSUM 3설정은 고치지 않았고 계속 탈락이다.

계산 순서·공유 임시값·행 재사용의 [세부 설명](R4_METHODS.md#비간섭과-안정성의-범위)을 별도로 둔다.

## 별도 평가 조건을 미리 만든 사고와 조치

검사 코드의 실수로 원래 별도 평가 시드 371501의 조건을 동결 전에 메모리에서 두 번 만들었다. 조건을 출력·저장하거나 시뮬레이션을 실행하지는 않았지만 사전 생성 금지 위반으로 기록했다. 후보 충돌 결과를 보기 전에 그 시드를 폐기하고 새 시드 371599로 바꿨다. 관문과 조건 범위는 그대로다. 실제 새 holdout은 코드와 선택을 동결하고 실행 시작을 한 번만 기록한 뒤 1회 진행했다. 재검증에서 쓴 질량 1.5173, 3.8051, 6.0473, 7.2303 kg은 동결 전에 새 별도 평가의 제외 목록에 추가했다.

## 계산 시간과 미달

| 방식·소스 | 최악 행 p99 [µs] | 관측 최대 [ms] | 1 ms 초과 주기 |
|---|---|---|---|
| A 서보/R1 | 260.611 | 0.501 | 0 |
| A 서보/W40 | 342.133 | 5.141 | 1 |
| B 토크/R1 | 307.692 | 5.257 | 3 |
| B 토크/W40 | 275.261 | 0.466 | 0 |

같은 새 사전 재검증 38조건/방식의 제어기+감지기 합산 벽시계 시간이다. 각 소스는 228,000주기이며, p99는 주기 시간의 99백분위값 중 가장 나쁜 조건의 값이다. p99 800 µs 관문은 통과했지만 A W40·B R1의 관측 최대 1 ms 목표는 미달이다. 직렬 실행 순서와 OS 부하의 영향이 있어 순수 알고리즘 속도 비나 시간 상한 보장으로 쓰지 않는다.

**보존된 R3 표:** 서보 R1은 p99 327.670 µs, 최대 11.703 ms, 1 ms 초과 8주기다. 토크 R1은 p99 350.440 µs, 최대 14.163 ms, 1 ms 초과 4주기다. **R1은 최대 1 ms 목표 미달이다.** R3 표의 원래 표시값을 그대로 인용했으며 재계측하지 않았다. 위 38조건 표와 평가 범위가 다르고 이 유한 표로 과거 미달이 해소됐다고 주장하지 않는다.

[보존된 R3 시간 표](R3_README.md#계산-시간과-미달)를 함께 본다.

G4 지속 지지, 약한 집기·놓기 충돌 감지, 보존 격자의 서보 포화, 섭동 오감지의 미달은 남는다. 최종 3파일은 R1이며 새 후보의 추적 개선이나 실기 안전을 주장하지 않는다.

## 요구사항 점검

기존 가이드 33항목의 24충족/4부분/5판정 불가와 입력·형식·무결성 8통과 판정은 최종 3파일이 R1과 같아 유지한다. 이는 모든 성능 목표의 충족이나 새 후보의 성공을 뜻하지 않는다. 판정 불가에는 선택하지 않은 권고 항목과 비공개 평가도 포함된다.

[가이드 요구와 자체 목표의 구분](REQUIREMENTS_AUDIT.md)은 기존 기록을 보존한다.

## 이번에 시도하지 않은 것

- 토크 추적 feedforward는 구현하지 않았고 효과는 모른다. 감지기의 추가 검출 여지를 먼저 시험해 2순위로 남겼다.
- 공식 8 kg 미검출 3조건에 W40을 실행하지 않았다. 집기 10·15 N과 놓기 10 N은 최종 R1의 미검출이며 W40의 개선 여부는 모른다.

## 한계

- D4는 이미 후보 설계에 사용한 기존 관측 자료의 재생이며 독립 효능 자료가 아니다.
- 새 잡음 9조건을 포함한 섭동은 유한 분석이며 실기 안전이나 확률 보장이 아니다.
- p99 800 µs는 선택 관문이고 최대 1 ms는 관측 목표다. 모든 초과 표본을 보존했다.
- 서로 독립이 아닌 정상 표본의 최대값으로 보정했으므로 정해진 확률로 오감지를 막는다고 보장하지 않는다.
- 감지기 비간섭 검사는 유한 조건이며 전역 안정성 보장이 아니다.
