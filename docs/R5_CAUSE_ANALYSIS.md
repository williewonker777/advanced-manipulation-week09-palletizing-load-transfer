# R5 구현 전 원인 분석과 개선 여지

A는 서보, B는 토크 방식이며 FA는 오감지다. 아래는 새 분석 전용 자료의 결과다. 채택·공식 성능이나 모든 학습 방법의 수학적 상한이 아니다.

## 사전 멈춤 규칙

방식별 새 충돌 90조건에서 추가 검출 3건 이상, 그중 집기 또는 놓기 1건 이상, 별도 정상 감사의 새 경보 표본·상승 0, 기존 R1 검출·툴 접촉 손실 0, 조건별 충돌 외 오감지 비증가를 한 설정이 동시에 만족해야 구현으로 넘어간다. 이 진입 기준은 후속 validation 2·development 2·D4 6·holdout 2의 채택 관문을 대체하지 않는다.

## 자료와 누출 방지

- 정상 적합 24조건/방식, 별도 보정 16조건/방식, 별도 감사 16조건/방식이다. 질량·COM·센서 시드를 분리했고 학습하지 않은 질량으로 확인했다.
- 분석은 새 질량 3개 × 집기·운반·놓기 × 대칭 10방향 = 90조건/방식이다. 별도 참조 3조건과 툴 접촉 양성 대조 4조건/방식을 두었다. 같은 질량의 참조와 외력 실행은 공통 잡음으로 짝지었으므로 독립 반복이 아니다.
- 허용 측정·관측기 파생 렌치/관절 잔차, 공개 reference, 알려진 질량·COM만 모델에 들어간다. 실제 링크각·토크·힘·접촉, 설정 강성/마찰·잡음 시드, 충돌 시각/힘/라벨은 학습 입력·목표가 아니다. 물리 비교 자료는 별도 파일로 격리했다.
- 평균·스케일·가중치는 정상 적합에서, 임계는 별도 정상 보정의 4연속 점수 최대 × 1.05에서 고정했다. 모든 모델 SHA를 고정한 뒤 정상 감사와 충돌을 열었다. 충돌 뒤 임계·가중치 수정은 없다.

| 방식 | 검출/90 | 힘이 가해진 동안 학습 분기 비활성 | 활성이나 학습 임계 미만 |
|---|---:|---:|---:|
| A | 54 | 20 | 16 |
| B | 52 | 23 | 15 |

이는 **R1 학습 분기 관점의 분류**다. 비활성이라는 사실만으로 기하·빠른 분기까지 포함한 최종 놓침의 단일 물리 원인이 증명되는 것은 아니다. 공식 원시 신호와 새 holdout은 쓰지 않았다.

## 판단과 다음 단계

- 상태별 log-scale 정규화가 A/B 모두 6건(집기 2·운반 4)을 더 잡아 멈춤 조건은 성립하지 않는다. 놓기 추가 검출은 0으로 남았다. 동일 중심 보정의 위상 MAD는 추가 0이므로, 단순 평균 예측 개선보다 상태별 정상 오차 크기 정규화가 유효할 가능성을 지지한다. 아직 독립 효능 결론은 아니다.
- 실제 후보는 SCALE 두 설정과 AR 20/50 ms 두 설정의 두 계열이다. SCALE_STATE만 두 방식에서 채택 가능성이 있다. SCALE_PHASE와 AR은 사전 진단 대조로 고정하며 이후 좋아져도 채택 후보로 되살리지 않는다. AR은 추가 검출이 있지만 조건별 충돌 외 오감지를 늘렸다.
- RFF는 활성 범위에서 추가 0, 확장 범위에서도 B 추가 2로 사전 기준에 못 미쳐 실제 후보에서 제외했다. 큰 신경망·정확한 GP 관측기·온라인 학습·지도 충돌 분류·제어 변경은 시도하지 않는다. 제한된 네 계열의 결과를 다른 모델의 불가능성으로 확대하지 않는다.
- 선택한 SCALE_STATE는 추가 실수 파라미터 263개/방식이다. 새 정상 감사·validation·development·D4·섭동·동결 이후 holdout과 공식 회귀의 관문을 모두 넘어야 채택한다. 실행 단독·합산 계산 시간은 실제 구현 뒤 직렬로 잰다.

## 수집 인프라 예외

완료 306실행 외에 RAM 안전 대기 중 자체 장기 수집 프로세스를 종료한 불완전 시도 1회가 있다. 그 부분 신호는 메모리에만 있어 저장되지 않았다. 결과를 열기 전에 동일 입력 1회 재시도 예외와 완료 182행의 SHA를 고정했고, 완료 행 재실행은 0이다. 남은 12조건은 실행별 독립 프로세스로 끝냈다. 순환 참조는 확인했지만 메모리 누적의 정확한 원인은 확정하지 않았다. 이 불완전 시도와 재시도를 숨기지 않으며 결과 기반 outlier 제거로 취급하지 않는다.
