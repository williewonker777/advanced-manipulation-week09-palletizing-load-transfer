# R6 발표 요약

## 1. 질문

R5 서보 후보의 수치 성능이 아니라 조립 결함만 고쳤을 때 제출 호환성, 저장 자료 동등성, 새 holdout과 공식 회귀를 모두 통과하는가?

## 2. 한 줄 수정

한 원소 문자열을 `('servo',)` 튜플로 만들었다. 모델 263개 파라미터와 임계값, 제어기, 관문은 그대로다.

## 3. 결함 재현과 계약

수정 전 알려진 예외를 회귀 검사로 재현했다. 수정 후 신규 5개 검사, 전체 534개 검사, 기본 제출 이름 8개 인터페이스 검사가 통과했다.

## 4. 저장 자료와 새 물리 동등성

새 full-loop 8회는 모두 완료됐고 사후 raw 검토에서 물리·packet·결정 비트가 같았다. 그러나 결과 직렬화가 실패했으므로 이 사후 검토는 실패한 S1 transaction을 수리하거나 통과로 바꾸지 않는다.

S1 결과 직렬화가 실패했으므로 사후 raw 검토의 비트 일치는 후보를 되살리는 통과 판정이 아니다. 알려진 직렬화 결함은 고치지 않았고 R1 fallback을 선택했다.

## 8. 결론

S1 결과 직렬화 실패로 R6 후보를 채택하지 않고 A 서보와 B 토크 모두 R1을 유지했다. holdout과 공식 평가는 열지 않았다. 재설계는 0회이며 실패 뒤 수리나 재실행을 허용하지 않았다.

## 9. 제한

- 새 holdout 계산 시간은 미실행이다. 최대 1 ms를 보장으로 주장하지 않는다.
- 무충돌 섭동 28 reference FA는 A 6→6, B 9→9다.
- 전체 34조건 FA는 A 6→6, B 10→10다. 28 reference 범위와 섞지 않는다.
- 탈락한 B STATE 진단값은 D4 추가 +5로 기준 6에 못 미쳤고, 28 reference FA가 9→10로 늘었다. R6 B에는 승계하지 않았다.
- 놓기 전 평균 지지율은 R1에서 A 0.2098; B 11.1507로 50 %mg 기준에 못 미친다.
- D4 R1 포화/놓기 peak는 A sat 2/189, peak 1.6098 mg; B sat 0/189, peak 1.0358 mg로 A 포화 0회와 peak 1.1 mg 기준을 만족하지 못한다.
- 유한 시뮬레이션 결과이며 하드웨어 안전 보장이나 충돌 정지 인증이 아니다.
