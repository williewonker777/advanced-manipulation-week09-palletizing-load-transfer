# R5 발표 자료 원고

## 1. R5 결론

- 새 후보는 채택되지 않았고 R1을 유지했다.
- R1 제어기는 고정하고 정상-only 감지 채널만 비교
- A=서보, B=토크, FA=오감지

## 2. 최종 제출 호환성 판정

- A STATE는 validation·development·D4·holdout과 공식 조건에서는 양의 측정값을 냈지만, 최종 제출 호환성 526개 검사에서 8개 오류가 발생해 탈락했다. 한 원소 모드 집합이 문자열로 생성되어 제어기 정보가 없는 reset에서 TypeError가 났다. 동결 뒤 수리·재평가하지 않고 미리 동결한 R1로 fallback했다.
- 최종 A/B 모두 R1, 최종 세 제출 파일은 R1과 바이트 동일
- 양의 sealed 측정값은 탈락 후보 기록으로만 보존
- 잠정 비교 영상 두 쌍은 보관 전용이며 공개 결과에 없음
