## 1. R4 결론과 용어

- 새 채택 0개, 최종 3파일은 R1과 바이트가 같다. 수정 W40은 D4에서 A +13, B +10 검출했지만 무충돌 섭동 FA가 A 6→9, B 9→17로 늘어 탈락했다. 모든 후보는 동결 전에 탈락했고 새 holdout은 R1 보존만 확인했다.
- A=서보, B=토크, FA=오감지
- W40은 현재까지의 40 ms 후행 평균으로 짧은 오차를 모아 보는 감지 방법이다.
- CUSUM은 정상 수준보다 큰 오차를 시간에 따라 누적하는 변화 감지 방법이다.
- D4는 질량·무게중심·외력을 넓힌 기존 개발 평가로, 방식당 385조건 중 충돌은 180조건이다.
- holdout은 후보 선정에 쓰지 않고 마지막에 한 번 확인하는 별도 평가 자료다.
- 동결은 별도 평가 전에 코드·보정값·최종 선택을 고정하는 절차다.

## 2. 문헌·원인·경험적 상한

- 새 문헌 10편: 원문 7, 기관 초록·서지 2, 출판 서지 1
- 높이 조건으로 학습 분기가 외력 전체에서 꺼진 놓침 A 43/B 46
- 40 ms 평균의 같은 자료 추가 분리 A 17/B 15; 4연속 A 13/B 14
- 놓침 69건 중 7점수 모두 정상 최대 이하: A 52/B 53
- 같은 자료를 쓴 진단이며 독립 효능·일반화 보장이 아니다.
- 토크 추적 feedforward는 구현하지 않았고 효과는 모른다. 감지기의 추가 검출 여지를 먼저 시험해 2순위로 남겼다.

## 7. 구현 문제와 한 번의 수정

- 최초 감지기는 모델의 임시값을 같은 값으로 다시 저장해 쓰기 금지 규칙을 어겼다.
- W40만 재설계 1회를 써 중복 저장을 없앴다. 가중치·통계량·임계값은 그대로다.
- 새 76조건에서 제어 궤적·물리값·감지 판정의 일치를 확인했다.
- CUSUM 3설정은 고치지 않았고, 이후 수치가 좋아도 채택하지 않았다.

## 8. 개발 검증·D4·섭동

- D4는 이미 설계에 사용한 기존 385조건/방식의 관측 재생
- 무충돌 28조건: W40 FA A 6→9, B 9→17로 양쪽 탈락
- 증가 A 3행/B 6행은 강성 ±20 % 조건(강성·마찰 조합 포함)
- 새 잡음 9조건은 증가 0; 전체 34조건 충돌 외 FA A 6→9/B 10→18
- 앞 단계에서 탈락한 후보는 뒤 수치로 되살리지 않았다.

## 9. 무충돌 보정·물리값 일치·시간

- 무충돌 검사 128행: 추가 경보 표본 0, 시작 0
- 물리값 일치 16행: 새 W40 대표 4행 + 기존 CUSUM 12행 재사용
- W40 새 전체 시뮬레이션 76조건과 최초 304행 기록 보존
- 같은 38조건의 p99는 모두 800 µs 미만; 엄격 최대 1 ms 목표는 미달
- A W40 최대 5.141 ms, B R1 최대 5.257 ms와 모든 초과 표본을 보존

## 10. 평가 조건 생성 사고와 R1 확인

- 검사 코드의 실수로 원래 별도 평가 시드 371501의 조건을 동결 전에 메모리에서 두 번 만들었다. 조건을 출력·저장하거나 시뮬레이션을 실행하지는 않았지만 사전 생성 금지 위반으로 기록했다. 후보 충돌 결과를 보기 전에 그 시드를 폐기하고 새 시드 371599로 바꿨다. 관문과 조건 범위는 그대로다. 실제 새 holdout은 코드와 선택을 동결하고 실행 시작을 한 번만 기록한 뒤 1회 진행했다. 재검증에서 쓴 질량 1.5173, 3.8051, 6.0473, 7.2303 kg은 동결 전에 새 별도 평가의 제외 목록에 추가했다.
- R1 holdout: A 20/30, 정상 FA 0, 전체 충돌 외 FA 0
- R1 holdout: B 22/30, 정상 FA 0, 전체 충돌 외 FA 1
- 모든 후보는 동결 전에 탈락; W40 holdout 미실행
